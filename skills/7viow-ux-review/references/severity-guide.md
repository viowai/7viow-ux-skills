# Severity

Use this reference when prioritizing a finding. Judge the observed or reasonably supported consequence for the intended task. Report uncertainty separately.

| Level | Consequence | Example |
|---|---|---|
| High | Blocks the main task, creates a serious decision error, excludes a necessary access mode, or causes material irreversible loss | Results suggest a different unit/time scope; a primary action is inaccessible; drafts disappear in a consequential editing flow |
| Medium | Task remains possible but requires avoidable memory/search, creates recoverable errors, or weakens important orientation | Comparison requires reading two long documents sequentially; returning loses the user's filter |
| Low | Local friction or inconsistent craft without a material task consequence | Minor spacing drift that does not obscure content or controls |

The same visual symptom can have different severity in different tasks. Explain why here. A comparison failure can be High if comparison is the principal decision task, Medium if it is an occasional supporting feature.

Do not equate a missing screenshot, unknown token, three-second impression, or extra hierarchy level with High. Those may be evidence gaps or cues to investigate. Keep old report labels intact when importing history; state any reinterpretation rather than mechanically mapping four levels into three.
