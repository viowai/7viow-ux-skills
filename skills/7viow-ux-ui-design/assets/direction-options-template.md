# Design direction decision

## Reading guide
Actual options/entrances; the user task they address; what decision is needed; how to respond; what happens after selection. Source and production notes remain outside product copy.

## Option A / B / optional C
For each: strategy; information grouping/order; primary interaction and recovery; priority-to-layout mapping; actual keyframe with representative content; narrow-screen behavior; failure check; advantages, costs and assumptions.

## Comparison and decision
Compare the substantive strategies across understanding, task completion, interaction effort, extensibility and implementation risk. Give a reasoned recommendation. Record user selection/combination or explicit delegated choice and its source. A later repair retains this decision unless new evidence changes it.
